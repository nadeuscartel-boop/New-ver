Kalusugan ng session

I-install bilang app

Gawing app sa phone o computer. Mabubuksan ito kahit offline at makikita ang huling status.

Mga group chat

I-tick ang mga GC na gusto mong sagutin ng bot. Sa naka-tick lang ito magcha-chat. Puwede mo ring i-ON/OFF sa mismong GC gamit ang !on / !off (admin). Kapag nag-restart ang server, kusa itong magre-resume.
Pindutin ang Refresh list…

Private message (PM) targets

I-tick ang tao na gusto mong rereplyan ng bot sa PM. Kapag nag-message siya sa bot account, sasagot ito ng troll replies tulad sa GC (kapareho ng lazy skip, limits, at typing). Sa naka-tick lang. Hindi pa nag-PM? Ilagay ang Facebook user ID sa ibaba.
Pindutin ang Refresh list…

GC name cycle

Iikot ang pangalan ng napiling GC hanggang i-Stop mo. Chat command: !gcname start / stop.

Group features

Dito na lang ginagawa ang Lock GC name at Set ALL nicknames. I-type ang gusto mong ilagay, tapos pindutin ang Start sa GC.

Mga admin

Mga Facebook ID na puwedeng gumamit ng admin commands (!gcname, !troll, !eco) sa chat. Laging admin ang mismong bot account. Isang ID kada linya, o paghiwalayin ng comma.
Para sa owner commands (!setbal, !additem), mag-set ng OWNER_IDS sa Railway Variables.
